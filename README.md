# 반민특위 재판정

1949년 반민족행위특별재판부의 특별검찰관이 되어 박흥식 사건을 조사하는 고1 한국사 역사 추리 게임.

## 배포 (GitHub Pages)
1. 새 저장소를 만들고 `index.html`, `style.css`, `app.js`, `data.js`를 저장소 맨 위에 올린다.
2. Settings → Pages → Branch: `main` / `(root)` → Save.
3. 1~2분 뒤 `https://<아이디>.github.io/<저장소이름>/`에서 열린다.

서버·로그인·외부 API가 필요 없다. 진행 상황은 학생 브라우저(localStorage)에만 저장된다.

## 구성
- `data.js` — 증거 카드, 법 조문, 조합 판정표, 연표, 출처. 내용을 고치려면 이 파일만 수정하면 된다.
- `app.js` — 게임 진행·판정 로직
- `style.css` — 디자인

## 역사 자료 원칙
- 사실 정보는 `data.js`의 `SOURCES`에 적은 자료로 확인한 것만 썼다.
- 신문 기사·문서 원문 발췌는 확보하지 못해 싣지 않았다. 카드마다 ‘원문 미수록(자료 확보 필요)’으로 표시했다.
- 도입부 장면은 ‘교육용 재구성’으로 표시했다. 플레이어 검찰관은 가상 인물이다.

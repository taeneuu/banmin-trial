# 반민특위 재판정

1949년 반민족행위특별재판부의 특별검찰관이 되어 박흥식 사건을 조사하는 고1 한국사 역사 추리 게임.

## 배포 (GitHub Pages)
1. 새 저장소를 만들고 `index.html`, `style.css`, `app.js`, `data.js`를 저장소 맨 위에 올린다.
2. Settings → Pages → Branch: `main` / `(root)` → Save.
3. 1~2분 뒤 `https://<아이디>.github.io/<저장소이름>/`에서 열린다.

서버·로그인·외부 API가 필요 없다. 진행 상황은 학생 브라우저(localStorage)에만 저장된다.

## 구성
- 진행: 1장 반민특위의 탄생(대화·세 기관 맞추기) → 2장 특별조사위원회의 조사(체포 장면·조사 기록 수집) → 3장 특별검찰부의 조사(증거 조합·기소장) → 4장 특별재판부의 공판(반박과 재반박·구형·실제 역사·성찰)
- `story.js` — 장 구성, 대화 대본, 세 기관 미니게임, 공판 반박 데이터. 모든 대사는 '교육용 재구성'이며 줄마다 기록 근거를 적었다.
- `images.js` — 사진 목록과 출처·라이선스. 증거 카드에 어떤 사진/일러스트를 붙일지도 여기서 정한다.
- `data.js` — 증거 카드, 법 조문, 조합 판정표, 연표, 출처. 내용을 고치려면 이 파일만 수정하면 된다.
- `app.js` — 게임 진행·판정 로직
- `style.css` — 디자인

## 선생님 제출 (구글 시트)
- 마지막 질문에서 학번·이름을 쓰고 제출하면 `app.js`의 `SUBMIT_URL`(광복 1945와 같은 Apps Script)로 보낸다.
- `apps-script.gs`가 스프레드시트의 Apps Script에 넣을 코드다. `app: 'banmin'`이 붙은 제출은 '반민특위 재판정' 시트에, 그 밖의 제출(광복 1945)은 기존 '응답' 시트에 저장한다.

## 이미지
- 사진은 모두 Wikimedia Commons에서 라이선스(퍼블릭 도메인, CC0, CC BY, CC BY-SA, 공공누리 1유형)를 확인한 것이다.
- Wikimedia 서버에서 직접 불러온다. 불러오지 못하면 회색 안내 패널이 대신 보인다.
- 사료 사진 / 참고 이미지 / 분위기용을 화면에 구분해 표시한다. 박흥식 본인 사진과 조선비행기공업 관련 사진은 공개 이용 가능한 것을 찾지 못해 넣지 않았다.

## 역사 자료 원칙
- 사실 정보는 `data.js`의 `SOURCES`에 적은 자료로 확인한 것만 썼다.
- 신문 기사·문서 원문 발췌는 확보하지 못해 싣지 않았다. 카드마다 ‘원문 미수록(자료 확보 필요)’으로 표시했다.
- 도입부 장면은 ‘교육용 재구성’으로 표시했다. 플레이어 검찰관은 가상 인물이다.
